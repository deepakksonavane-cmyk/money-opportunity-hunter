# Money Opportunity Hunter - Super Simple Version

## How to use

### Method 1: Just click the file (EASIEST)

1. Find the file called `index.html` in the project folder
2. **Double-click it**
3. It will open in your browser
4. Done!

### Method 2: If Method 1 doesn't work

Right-click `index.html` → Choose "Open with" → Select Chrome, Edge, or Firefox

## What you see

- A big purple button that says **"+ ADD NEW OPPORTUNITY"**
- A list of opportunities that are already there
- Each opportunity shows:
  - Name and platform
  - How much it pays
  - How many days it takes
  - A score (how good it is for you)
  - A status badge (NEW / BID / WON / LOST)

## How to use it

1. **See the opportunities** - They're ranked best first
2. **Add a new one** - Click the big purple button
3. **Filter by status** - Click NEW, BID, WON, or LOST to see only those
4. **It saves automatically** - Your data stays in the browser

## That's it!

No coding, no Python, no commands. Just open the file and use it like any other webpage.
